# Bozkir
Bozkır is a crop rotation decision-support system using NASA Earth observation data for sustainable water and soil management. Developed for NASA Space Apps Challenge 2026 – Field Shift: Adapting Farms with NASA Data.



## Scientific limitations

See [Scientific assumptions](docs/SCIENTIFIC_ASSUMPTIONS.md).

Crop dates and growth stages are illustrative.
Initial Kc is assumed.
ETc is not irrigation demand.
